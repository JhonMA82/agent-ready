## Conventions used here

- **`agent-ready <command>`** — the CLI, run in a terminal.
- **`/agent-ready <mode>`** — the OpenCode slash command, run inside OpenCode.
- **Facts vs. decisions** — the CLI emits deterministic JSON facts; the model interprets them. The CLI never decides what a repository "needs".
